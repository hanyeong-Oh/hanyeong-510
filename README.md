# English Study Club 📚

직장 동료와 둘이서 하는 영어 공부 사이트입니다. 흰 바탕에 투박한 검은 선, 회색 띠, 펜 손글씨(Nanum Pen Script)와 가나디 스티커로 꾸몄어요. 빌드 과정 없이 HTML/CSS/JS로만 만들어서 `index.html`을 더블클릭하면 바로 열립니다.

## 주요 기능

### 1. ✍️ 영어 글쓰기 (주 3회)
- **각자 주제 정하기**: 월·수·금(설정 가능)마다 두 사람이 **각자 자기 주제**를 정해요. 홈의 날짜 칸에 사람마다 한 줄씩 주제와 상태가 보이고, `+ 내 주제`로 정해요. 같은 날 내 주제는 하나, 주제 수정·삭제는 주제 주인만 할 수 있어요. (예전에 만든 공통 주제는 `같이`로 표시되고 둘 다 써요)
- **작성 상태**: 미작성 → **작성중**(`작성중 저장`, 동료에겐 내용 대신 "작성 중"만 보임) → **작성완료**(`작성 완료`, 동료에게 보임) → 검수완료(수정본 입력). 진행 현황 숫자는 작성 완료한 글만 세요.
- **오늘 할 일**: 홈 맨 위에 오늘(또는 밀린·다음) 내 주제와 `쓰러 가기 / 이어 쓰기 / 검수본 입력` 버튼이 바로 보여요.
- **직접 쓰기**: 각자 주제에 맞춰 영어로 글을 씁니다. 단어 수·문장 수가 표시되고, 영어 맞춤법 검사가 켜져 있어요.
- **임시 저장**: 쓰는 중인 글은 이 브라우저에 자동 보관돼요. AI 창에 다녀오다 페이지를 닫아도 다시 열면 불러와요. (`작성 완료`를 눌러야 동료에게 보여요)
- **따라 쓰기 방지**: 내 글을 쓰기 전에는 동료 글이 가려져 있어요. `그래도 보기`로 열 수 있어요.
- **AI 검수**: `AI에게 보낼 질문 복사` 버튼을 누르면 내 글이 들어간 검수 요청문이 복사됩니다. ChatGPT, Claude, Gemini 등에 붙여넣으세요.
- **수정본 입력**: AI가 고쳐준 수정본과 피드백(배운 표현)을 사이트에 따로 입력합니다.
- **비교 보기**: 원문과 수정본을 자동으로 비교해서 <del>지운 부분</del>은 빨간색, <ins>바뀐 부분</ins>은 초록색으로 보여줍니다.
- **수정 내역 · 원어민 표현**: AI 검수 요청문은 교과서 문법보다 *원어민이 실제로 쓰는 표현* 기준으로 검수하도록 짜여 있어요. AI 답변 2번을 붙여넣으면 `[문법]`(실제로 틀린 것) / `[원어민]`(문법은 맞지만 원어민은 다르게 말하는 것) / `[표현]`(원어민이 자주 쓰는 표현)으로 자동 정리됩니다.
- **문법 개념**: 초보자에게 필요한 순서대로 19개 — 문장의 뼈대(거품 빼기) → 시제 → 2형식 → 2형식 동사 → look·seem·appear → 자동사·타동사 → 관사 a·the → 전치사 → for와 to → 접속사·시간 표현 → 조동사 → to부정사·동명사 → 분사·분사구문 → 5형식(목적격보어) → 비교 → 수동태 → 관계사 → 명사절 → 가정법. 카테고리마다 기초 개념 → 핵심 정리 → 원어민 감각 → 자주 하는 실수 순서로 쉽게 정리했어요. 예문은 🔊로 들을 수 있고, 관련 유튜브 영상(🎬)이 있는 카테고리는 바로 열어 볼 수 있어요. 강의 그림은 `images/grammar/`에 있고, 섹션의 `images: [[경로, 설명]]`으로 붙여요. 내용과 순서는 `js/grammar.js`에서 고칠 수 있어요.
- **표현 노트**: 두 사람이 정리한 문법 실수·원어민 표현을 한 페이지에 모아 종류·멤버별로 보고 검색할 수 있어요. `가리고 복습`을 켜면 고친 문장·영어 표현을 가려 두고 탭해서 확인하는 퀴즈처럼 쓸 수 있어요. (섞기 · 전부 보기)
- **이 글에서 꼭 기억할 것**: 내 글 아래에서 꼭 외울 문법·영단어를 바로 내 노트에 챙겨요. 수정 내역 줄마다 `+ 노트`, 글에서 단어를 드래그하면 `+ 단어장`, 직접 적기, AI 답변 5번(`[단어]` / `[핵심문법]`) 한 번에 붙여넣기 — 모두 어느 글에서 나왔는지 함께 저장돼요.
- **내 노트**: 나만 보는 메모장. 영단어 · 영어 문장 · 문법 · 기타를 날짜별로 적어 둬요. 날짜를 골라 그날 메모만(종류별로 나눠서) 보거나 종류·검색으로 찾고, `뜻 가리기`로 외웠는지 확인할 수 있어요. 동료에게는 보이지 않아요 (DB 권한으로 막혀 있음).
- **🔊 듣기**: 문법 예문, 수정 내역의 고친 문장·표현, 수정본 전체를 원어민 발음(브라우저 음성)으로 들을 수 있어요.
- **진행 현황**: 홈에서 이번 주 3회차의 작성/검수 상태와 멤버별 누적 기록(작성 글 수, 검수 완료 수, 누적 단어 수)을 볼 수 있습니다.

### 2. 🎬 영어공부 영상
- 유튜브 링크(`youtube.com/watch`, `youtu.be`, `shorts` 등)를 붙여넣으면 썸네일이 나오고 제목도 자동으로 채워집니다.
- **재생목록 링크**(`youtube.com/playlist?list=...`)도 넣을 수 있고, 사이트 안에서 재생목록 전체가 이어서 재생됩니다.
- 처음 열면 `js/config.js`의 `DEFAULT_VIDEOS`에 적어둔 영어공부 영상과 재생목록 16개가 기본으로 들어가 있습니다. 이 목록에 나중에 추가해도 아직 안 들어간 것만 자동으로 추가됩니다. (Supabase는 `schema.sql` 실행 시 추가)
- 카테고리: 리스닝 / 스피킹 / 문법 / 어휘·표현 / 발음 / 비즈니스 영어 / 기타 (`js/config.js`에서 수정 가능)
- 카테고리 필터, 검색, 메모, 멤버별 **시청 완료** 표시
- 썸네일을 누르면 사이트 안에서 바로 재생됩니다.

## 파일 구조

```
index.html          # 페이지 뼈대
css/style.css       # 디자인
js/config.js        # ⭐ 설정 (멤버 이름, 글쓰기 요일, 영상 카테고리, Supabase 키)
js/store.js         # 데이터 저장 (로컬 / Supabase)
js/mascot.js        # 가나디 스티커 표시
images/ganadi/      # 가나디 스티커 이미지 (배경 투명 PNG)
js/grammar.js       # 문법 개념 내용
images/grammar/     # 문법 개념에 붙는 강의 그림
js/diff.js          # 원문·수정본 비교
js/app.js           # 화면과 기능
supabase/schema.sql # Supabase 테이블 생성 SQL
```

## 시작하기

### 1단계 — 설정 바꾸기
`js/config.js`에서 멤버 이름을 바꿉니다.

```js
MEMBERS: [
  { name: '오한영', email: '' },
  { name: '박정민', email: '' },
],
TOPIC_MANAGER: '오한영',   // 예전 공통 주제(같이 쓰는 주제)를 고칠 수 있는 사람
WRITING_DAYS: [1, 3, 5], // 월·수·금
```

### 2단계 — 바로 써보기 (로컬 모드)
`index.html`을 브라우저로 열면 됩니다. 이때는 **이 브라우저에만** 저장되므로 혼자 테스트할 때 쓰세요.
(상단 배너의 `백업 내보내기/가져오기`로 JSON 백업 가능)

### 3단계 — 동료와 함께 쓰기 (Supabase, 연결 완료)
`english-study-club` Supabase 프로젝트(서울 리전)에 연결돼 있습니다. `js/config.js`에 주소와 anon 키가 들어 있어요.

- **처음 접속하면** 로그인 화면에서 `처음이면 가입하기` → 등록된 멤버 이메일 + 원하는 비밀번호(6자 이상)로 가입하면 바로 시작됩니다. 인증 메일이 와도 무시해도 돼요.
- **멤버 이메일**은 공개 저장소에 올라가지 않도록 Supabase의 `members` 테이블에만 저장돼 있습니다. 바꾸려면 Supabase 대시보드 → **Table Editor → members** 에서 수정하세요.
- 멤버가 아닌 이메일은 가입하더라도 아무 데이터도 볼 수 없습니다 (RLS).
- 처음부터 새로 만들 때는 `supabase/schema.sql`을 SQL Editor에서 실행하고, 맨 아래 예시처럼 `members`에 두 사람 이메일을 넣으면 됩니다.

> anon 키는 공개돼도 괜찮은 키입니다. 데이터는 멤버로 로그인해야만 보입니다.

### 4단계 — 인터넷에 올리기 (GitHub Pages, 무료)
1. 이 저장소의 **Settings → Pages**
2. **Source: Deploy from a branch**, Branch: `main` / `/ (root)` 선택 후 Save
3. 잠시 후 `https://<깃허브아이디>.github.io/<저장소이름>/` 주소로 접속할 수 있습니다. 이 주소를 동료에게 공유하세요.

## 사용 흐름

1. 주제 담당(오한영)이 홈에서 `+ 주제 정하기` → 주제 입력
2. 각자 `쓰러 가기 →` 눌러 영어로 글쓰기 → 저장
3. `AI에게 보낼 질문 복사` → AI에게 검수 받기
4. 받은 수정본 / 피드백을 `검수본 입력`에 붙여넣기 → 저장
5. 주제 페이지에서 서로의 원문·수정본·비교를 보며 같이 복습 💪

## 이미지 출처

`images/ganadi/` 의 캐릭터 이미지는 카카오톡 이모티콘 **가나디**의 스티커입니다. 저작권은 원작자에게 있으며, 이 사이트에서는 두 사람의 비상업적 스터디 용도로만 사용합니다.
